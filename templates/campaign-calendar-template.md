# COBE Campaign Calendar Template

Use this template to plan multi-channel campaign timelines. Work backwards from your event date.

| Week | Action | Channel | Owner | Status |
|------|--------|---------|-------|--------|
| 6 weeks out | Book room, confirm speakers, create registration | Logistics | Requester | |
| 6 weeks out | Contact Career Services (if employer event) | Email | Requester | |
| 4 weeks out | Email cobe-info@boisestate.edu with creative brief | All | Requester | |
| 3 weeks out | Submit to Localist (university calendar) | Web | Requester | |
| 3 weeks out | LinkedIn post scheduled | LinkedIn | COBE Marketing | |
| 3 weeks out | Newsletter mention submitted | Email | COBE Marketing | |
| 2 weeks out | Instagram posts begin | Instagram | COBE Marketing | |
| 2 weeks out | MBEB screens live | Signage | COBE Marketing | |
| 2 weeks out | Classroom slides distributed | Internal | Requester/COBE | |
| 1 week out | Email reminder sent | Email | COBE Marketing | |
| 1 week out | Instagram story reminder | Instagram | COBE Marketing | |
| Event day | Signage in place, photographer assigned | On-site | Requester | |
| Event day | Post-event survey ready | Email/Web | Requester | |
| 1 week after | Post-event recap (photos, metrics) | Instagram/LinkedIn | COBE Marketing | |

## Notes
- Hands-Off: COBE Marketing handles copy, design, scheduling, and approvals after you submit facts.
- Hands-On: You draft copy and create graphics using COBE templates; COBE Marketing reviews and approves.
- All requests start at cobe-info@boisestate.edu.
